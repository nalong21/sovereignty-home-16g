# Household onboarding (printable)

Ultra-short bullets for household members. Operator details stay in [onboarding-card.md](onboarding-card.md).

1. **Away access** — Install the official **Tailscale** app; the operator points it at household **Headscale** (not Tailscale’s default SaaS, unless they say otherwise).
2. **Passwords** — Use the **Vaultwarden** URL the operator shared (Bitwarden-compatible app/extension).
3. **Photos** — Use **Immich** for family photos/videos.
4. **Email** — Never give out a real inbox for signups; use the household **alias** service (SimpleLogin or addy.io) the operator set up.
5. **Questions / lockout** — Ping the operator named on the full onboarding card.
